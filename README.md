## วิธีติดตั้ง

1. โคลนโปรเจกต์:
   ```bash
   git clone https://github.com/chsnor/git_flowcahrt.git
   cd git_flowcahrt
   ```

2. ลงแพ็กเกจ:
   ```bash
   npm install
   ```



---

## วิธีใช้งาน

1. รันเซิร์ฟเวอร์สำหรับทดสอบ:
   ```bash
   npm run dev
   ```

2. เข้าใช้งานผ่านเบราว์เซอร์:
   ```
   http://localhost:3000
   ```

3. การใช้งาน:
   - นำ URL ของ GitHub repo ที่ต้องการดูผัง (เช่น `https://github.com/owner/repo`) มาวางในช่องค้นหา
   - กดปุ่มค้นหาเพื่อเริ่มแปลงโค้ดเป็นไดอะแกรม
   - คลิกที่โหนดเพื่อดูการเชื่อมโยง หรือคลิกเพื่อเปิดดูโค้ดจริงในแถบด้านขวา
